# Интерфейс GrabYou

GrabYou помогает найти срочные предложения локального бизнеса, оплатить заказ
и забрать его по QR. Главная страница знакомит с сервисом; основное действие —
открыть приложение. Страница `/download` помогает выбрать канал, `/partners` —
понять условия и оставить заявку от бизнеса.

## Визуальное направление

Сохраняем существующий характер: лайм, чернила, зелёные оттенки, карта Петербурга,
фирменный вордмарк и реальные экраны приложения. Жёсткая смещённая тень остаётся
на основных действиях и продуктовых блоках; информационные блоки спокойнее.

- Семантические цвета, размеры и геометрия находятся в `src/css/custom.css`.
- Дисплейная пара — Bulatov SP / Unbounded; основной текст — Cygre / Onest.
  Лицензированные шрифты используются локально, инструкция — `static/fonts/README.md`.
- Один h1 на страницу. Крупная акцентная типографика — для главного сообщения;
  описания и заголовки карточек читаются без избыточных прописных букв.
- Основное действие — лаймовая кнопка с тёмным текстом. На лаймовой поверхности
  она инвертируется. Вторичное действие — контурная кнопка.
- Контент и реальные экраны важнее декоративных рамок и повторяющихся подписей.
  Примеры предложений на карте явно обозначены как примеры.

## Взаимодействие

- От 44 px для отдельных интерактивных целей, от 48 px для основных кнопок и полей.
- Фокус: тёмно-зелёный контур на светлом фоне, лаймовый на тёмном.
- Мобильное меню и заявка используют нативный dialog: изоляция фокуса, Escape,
  возврат фокуса. Меню появляется сразу, без задержки.
- Поля заявки сохраняются после закрытия. Успех показывается только после ответа
  API `{ok: true}`; закрытие подтверждения очищает заявку.
- Открытие формы мышью: один контейнер, 200 ms, opacity и translateY.
  Для клавиатуры — сразу, для reduced motion — только opacity.
- Нет бесконечного движения, счётчиков через React на каждом кадре или скрытого
  до прокрутки содержимого. Состояния доступны без анимации.

## Проверка изменений

Проверять три маршрута на 390, 768 и 1440 px, дополнительно 320 px и увеличение
текста до 200%. Горизонтальная прокрутка допустима внутри подписанных галерей
экранов и примеров предложений; документ и основные действия не обрезаются.
Длинные данные проверяются через реальные поля формы, запросы — через API-моки.
